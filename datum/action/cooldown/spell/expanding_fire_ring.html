expanding_fire_ring
/datum/action/cooldown/spell/expanding_fire_ring

Expanding Fire Ring Spell Deals fire damage in an expanding circle around the caster.

Vars

damage_casterWhether the caster takes damage from their own ring.
expansion_delayDelay between successive rings.
fire_damageDamage dealt to each victim, per ring that passes over them.
max_rangeFurthest radius the ring expands to.
start_radiusRadius the first ring spawns at. 0 = the caster's own tile.
turf_hotspot_volumeHotspot volume left on each turf.
turf_temperatureTemperature (in Kelvin) the ring leaves on each turf it passes over.
visual_effectVisual effect spawned on each affected turf. Null disables it.

Procs

ring_turfsReturns every turf at exactly radius Chebyshev distance from center. radius <= 0 returns the centre tile by itself.
