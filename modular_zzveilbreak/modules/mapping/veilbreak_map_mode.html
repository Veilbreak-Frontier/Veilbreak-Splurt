/tg/ Station 13 - Modules - Types

modular_zzveilbreak/modules/mapping/veilbreak_map_mode.dm

/var/veilbreak_map_modeCurrent effective map mode. Resolved lazily from the persisted override file, then config.
/var/veilbreak_map_mode_statsPersisted statistics: { "history": [...], "wins": { "STANDARD": {...}, "BROAD": {...} } }
/proc/veilbreak_get_map_modeReturns the current effective map mode (MAP_MODE_STANDARD or MAP_MODE_BROAD).
/proc/veilbreak_load_map_mode_statsLoads (or initializes) the persisted map mode statistics.
/proc/veilbreak_save_map_mode_statsWrites the map mode statistics to disk.
/proc/veilbreak_get_map_mode_historyReturns the switch history list.
/proc/veilbreak_get_map_mode_winsReturns the per-mode win counts: wins[mode][map_name] = count.
/proc/veilbreak_record_map_winRecords a map vote win under the given mode.
/proc/veilbreak_normalize_map_modeNormalizes and validates a mode string. Returns the canonical mode or null if invalid.
/proc/veilbreak_map_allowedReturns TRUE if the given map config is allowed under the current mode.
/proc/veilbreak_allowed_map_namesReturns a list of map names allowed under the current mode.
/proc/veilbreak_allowed_map_names_textHuman readable list of allowed map names.
/proc/veilbreak_announce_map_modeBroadcasts a chat notice describing the current mode and allowed maps.
/proc/veilbreak_sanitize_map_vote_cacheRemoves tallies for maps that are no longer allowed under the current mode.
/proc/veilbreak_set_map_modeSets the map mode, persists it, announces it, and refreshes the map vote cache.
/proc/veilbreak_build_map_mode_stats_dataBuilds the full statistics payload for the TGUI panel.
/proc/veilbreak_build_csv_exportBuilds a CSV export of the per-mode win statistics.
/proc/veilbreak_show_lobby_map_statusShows the current map mode once to a player loading into the lobby.
