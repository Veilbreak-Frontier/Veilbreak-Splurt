display_to
(/mob/show_to, /datum/tgui_window/window)

Ensures the preferences character preview map_view is only registered to the client's screen once BOTH the parent TGUI window is visible AND the ByondUi map control has actually been mounted on the client.

If BYOND registers screen objects to a secondary map control while the parent window has is-visible = false or before the map control exists, BYOND falls back to world.view (15x15 tiles) instead of auto-fitting the 1x1/2x2/3x3 preview canvas, rendering a tiny "micro" character.
